01 / Motivation

A loss curve is a summary, not an explanation

Two models can reach similar loss while their layers organize in very different ways. Those differences are easy to miss when weights, gradients, activations, and attention are buried in separate logs.

We built this site as a microscope for optimization: connect internal measurements to the architecture, keep training time visible, and make comparisons cheap enough that an odd curve can become a research question.

03 / A small demo

One layer moves through three regimes

Consider attention_entropy_mean, a measure of how diffuse attention is across key positions. In the baseline run, Block 1 pauses near 4, drops to a second plateau near 2, then rises toward 2.5.

Block 1 is zero-indexed: it is the second transformer block.

What is being measured?

H̄ = Eb,h,q [ −Σk pk log pk ]

Higher values mean more diffuse attention; lower values mean more concentrated attention. The site keeps the formula beside the curve so the visual pattern stays tied to a precise quantity.

04 / Compare in place

The pattern becomes clear only in context

A strange curve is more useful when we can ask whether it is specific to one layer or one setup. These are the comparisons the Explorer is designed to make directly.

Working hypothesis · not yet a conclusion

Are 2 and 4 attractor-like entropy regimes?

Block 1 repeatedly returns to the same approximate levels, but in a different order. With warmup, entropy settles near 4 before descending to 2. Without warmup, it falls to 2 almost immediately, then rebounds toward 4.

With warmup ≈4 → ≈2 → 2.5 staged descent, then partial recovery
Without warmup ≈2 → ≈4 → 3.5 early collapse, then rebound

One possible reading is that learning-rate warmup helps attention entropy decrease in a controlled order: it prevents an immediate collapse into the low-entropy state and allows the ≈4 regime to stabilize before the transition toward ≈2.

Secondary clue · speculative

A faster Block 0 collapse may shorten the effective context

Without warmup, Block 0 attention entropy falls much faster and finishes far below the baseline. If eH is used as a rough effective number of attended positions, this resembles a sharp reduction in effective context length—even though the model's literal context window has not changed.

Our guess is that warmup may preserve broader early attention long enough for the rest of the network to organize more stably. This is a mechanism to test, not an explanation established by the curves.

From observation to research question

This is what the library is for

The curves do not yet explain why Block 1 reorganizes around 10–20k and 50k steps. They do something equally important first: localize the event, show that it is layer-specific, and reveal that depth and warmup change its character. A concrete next test is whether warmup prevents an early loss of effective context in Block 0, allowing Block 1 to move between the ≈4 and ≈2 regimes in a more stable order. That turns an impression into a testable question.
